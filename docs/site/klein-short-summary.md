## 100 Words

Klein Conformance Protocol (KCP) is a public-alpha protocol stack for producing, packaging, signing, and independently verifying evidence of physical-substrate execution attempts under uncertainty. The current alpha includes canonical artifacts, runbooks, traces, HAIL evidence, signed manifests, portable `.kcprun` bundles, local trust policy, backend identity and capability fixtures, Python and Rust verifier surfaces, a DMF/EWOD simulator profile, HIL readiness, recorded-run archives, generic/OpenDrop dry-run adapter skeletons, disabled OpenDrop transport planning, and timestamp/attestation stub boundaries. It verifies evidence artifacts and trust bindings. It does not claim hardware support, HIL execution, sensor proof, timestamp proof, hardware attestation proof, TPM/TEE verification, real OpenDrop control, or production certification.
