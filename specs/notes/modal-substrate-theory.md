# Modal Substrate Theory: Why Klein Exists

This note is conceptual, not normative protocol law.

Klein is the technical substrate layer of a larger modal architecture: it preserves reachable
execution paths through resistant media by making constraints, divergence, evidence, and repair
attempts explicit.

The useful mapping is:

- current executable substrate state -> extant state
- valid downstream execution paths -> reachable future state-space
- impedance, defects, drift, uncertainty -> resistance
- loss of reachable safe execution paths -> contraction or harm
- bounded path selection -> geodesic action cost
- HAIL -> evidence
- ECRP -> bounded repair evidence

Core specifications should remain small, technical, and testable. This note explains why the
protocol exists; it does not add conformance requirements.
